# 【祝贺】我院药学部被评为 PCCM 咳喘药学服务门诊全国示范中心

> 更新时间：2026-09-16 (UTC+8)

2020年11月14日，在中国药学会药学服务专委会年会上，**我院同北京朝阳医院、四川大学华西医院等23家医院被评为首批PCCM咳喘药学服务门诊全国示范中心。该项殊荣在华北地区亦属首例。**

此项目为中国医师协会呼吸医师分会、中华医学会呼吸病学分会、中国药学会药学服务专业委员会三大学会共同发起的 “呼吸与危重症医学规范化建设项目。”

**好棒啊，那这个门诊主要为患者做些什么呢**

慢性呼吸系统疾病已成为 “世界四大慢病” 之一，以哮喘和慢性阻塞性肺病（COPD）最为常见。吸入治疗是慢性呼吸系统疾病常见的给药方式，而吸入装置的正确使用是治疗的关键要素。

为了使慢性气道疾病的药物治疗管理更加系统化、规范化和标准化，更好地为咳喘患者服务，我院开设了咳喘药学服务门诊。

**门诊地点**

门诊楼一楼 药物咨询门诊诊室

**开诊时间**

每周一全天

**出诊专家**

由我院取得国家临床药师培训资质及PCCM项目考核通过的专科呼吸内科及抗感染专业临床药师出诊。

**目前，我院咳喘药学门诊免费为患者看诊哦。快来了解一下诊治范围和服务内容吧。**

**诊治范围**

慢性阻塞性肺疾病（COPD）、哮喘、支气管扩张等慢性呼吸系统疾病患者。

**服务内容**

1. 对我院就诊的哮喘或慢阻肺患者提供吸入剂正确指导（包括噻托溴铵粉吸入剂、噻托溴铵喷雾剂、沙美特罗氟替卡松粉吸入剂、布地格福雾化吸入、乌美溴铵维兰特罗吸入粉雾剂等常用药物）；

2. 支气管扩张药、祛痰药、抗微生物等相关药物不良反应预防与自我监护；

3. 慢病（如支气管哮喘、慢性阻塞性肺疾病、肺间质纤维化等）患者日常用药管理与疑难随访；

4. 针对呼吸系统合并心脑血管疾病患者，进行多学科用药整合及用药注意事项宣教等服务（专业的全程化优质药物宣教、指导与监护服务，解决咳喘患者用药过程中各类问题）。

**咨询电话**

0311-85988843

**科室介绍**

河北省人民医院药学部是河北省重点学科，下设药品库、门诊药房、急诊药房、口服药调配室、静脉用药集中调配中心、药物咨询门诊、临床药学、临床药理、试剂采购等部门，可为患者提供全流程、多学科、更专业的药品供应及药学技术服务。

药学部始终坚持“以病人为中心”的服务理念，除药品供应外，还积极开展了一系列专技型药学服务项目，如：住院及门诊患者全医嘱审核，确保患者用药安全；开展治疗药物监测15年，可进行环孢素、他克莫司、拉莫三嗪、甲氨蝶呤、丙戊酸、卡马西平、奥卡西平、苯妥英、苯巴比妥、万古霉素、去甲万古霉素、伏立康唑等药物的血药浓度监测；为住院患者提供全程静脉输液调配；对药品不良反应实施监测与干预等工作。

药学人的服务宗旨是：为医院提供最优质的药品，为患者提供最优良的药学专业技术服务。构建身心和谐、健康智慧的学科文化，谨遵药师职业道德，以高超精湛的药学专业技术为患者奉献爱心，保障患者最大受益。
